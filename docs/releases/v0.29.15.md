# tabrelio 0.29.15 阶段开发预览

- MySQL／MariaDB 数据传输源表目录支持独立任务编号和取消，旧备份目录调用保持兼容。
- 数据传输源表目录可按表名筛选，空结果明确提示，可选择当前筛选全部或清空；筛选外已选表会保留并参与合并，超过32张表时整批拒绝，不静默截断。
- 结构比较结果支持选择当前筛选项，筛选外选择保留，超过100项时整批拒绝；不可可靠比较的结果不会进入同步预览。
- 保存查询整理支持选择当前筛选全部。该操作用独立分页游标扫描当前已应用的分组、来源、默认库、收藏、文字和排序条件，仅收集概要；扫描失败或超过100条时整批拒绝，当前页续读游标保持不变。

本次源码验证包含保存查询界面37项、数据传输界面4项和结构比较界面30项定向测试，类型检查和生产构建通过。测试使用本机 Node 24.14.0 直接脚本运行，未满足项目要求的 Node 24.17.0；Windows、macOS x64、实库及安装包验收未在本机执行。

本机生成 macOS arm64 未签名 DMG 和 ZIP。Windows x64 和 macOS x64 产物不在本次本机附件中，macOS 应用未经 Apple 公证。版本以 GitHub prerelease 发布。
