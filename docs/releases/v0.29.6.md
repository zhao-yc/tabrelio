# tabrelio 0.29.6 阶段开发预览

- 表页、查询结果和离线快照的网格右键菜单新增「查看单元格值」。只读及不可编辑数据格也可以用 Windows `Alt+Enter` 或 macOS `Option+Enter` 打开。可编辑格仍可用快捷键编辑。
- 长文本支持分段浏览、区分大小写查找和原样复制，保留 CRLF 和 Unicode 字符边界。二进制值可查看十六进制、严格解码文本及受支持的图片。SQL NULL、DEFAULT 和空字符串分别显示。
- 查看面板使用当前已载入的值，关闭后焦点返回原数据格，切换来源后旧预览失效。

完整值功能已在本机 Electron 的 SQLite 和隔离环境的 PostgreSQL 18.6、MySQL 8.4.11、MariaDB 11.4.13 上核对。SQLite 完整值用例纳入 Windows x64、macOS arm64 和 macOS x64 的源码及安装包验收。本版继续修复跨平台阶段验收，包括小屏界面、macOS 显示租约以及剪贴板栈重开交互。[0.29.5 验收记录](https://github.com/zhao-yc/tabrelio/actions/runs/43408931322)

发行包含 Windows x64 安装程序、两个 macOS 架构的 DMG 和 ZIP、源码 ZIP 及 SHA256 清单。Windows 安装程序未签名，macOS 应用使用临时签名且未经 Apple 公证。
