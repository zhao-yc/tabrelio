# tabrelio 0.29.14 阶段开发预览

- 新增「工具 → MySQL／MariaDB 数据传输」。可在两个已保存连接之间选择源库、目标库和多张普通 InnoDB 表，选择「仅结构」或「结构及数据」，先预览建表 SQL，再输入准确目标库确认。
- 数据传输在写入前检查同名表或视图、服务器系列、主次版本、严格 SQL 模式和目标可写状态。建表完成后回读结构，数据模式在目标事务中写入并回读精确小数、文本、NULL 和二进制值。
- 「结构比较与同步」可对受支持的 MySQL／MariaDB InnoDB 表应用新增字段、默认值或注释变化和新增索引。执行前重新读取目标定义，生成单条 `ALTER TABLE`，执行后回读差异。外键变更、删除、复杂字段属性和整库对象编排仍保留为后续范围。

本版已在 macOS arm64 源码 Electron 中使用 Server-200 的独立 MySQL 8.4.11 和 MariaDB 11.4.13 源、目标实例核对多表传输、仅结构传输、同名拦截、目标预览漂移拒绝、精确数据回读和结构同步回读。Windows 和 macOS x64 由发行工作流执行同一版本的构建门禁。

发行包含 Windows x64 安装程序、两个 macOS 架构的 DMG 和 ZIP、源码 ZIP 及 SHA256 清单。Windows 安装程序未签名，macOS 应用使用临时签名且未经 Apple 公证。版本仍为 GitHub prerelease。
