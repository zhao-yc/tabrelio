# tabrelio 0.29.0 阶段开发预览

本版把表页、查询结果和离线快照的单元格查看补齐为独立的只读工作流。`v0.29.0` 标签用于阶段性开发预览，发布资产仍须经过标签触发的 Windows x64、macOS arm64 和 macOS x64 构建及安装验收。

## 本版行为

- 数据格右键菜单提供「查看单元格值」。只读格及不可编辑格支持 Windows `Alt+Enter` 或 macOS `Option+Enter`，可编辑格的快捷键继续进入现有编辑器。
- 长文本使用 65536 个 UTF-16 代码单元分段，保留 CRLF 和 Unicode 代理对边界，支持区分大小写查找及复制完整原文。复制内容不经过网格 TSV 编码。
- 二进制值复用只读 `BinaryCellViewer` 查看 Hex、严格解码文本及受支持的图片。SQL NULL、未填写的 DEFAULT 和空字符串分别显示。
- 查看面板只使用已经载入的值，切换标签、连接版本、活动任务、草稿或物理数据格后自动失效。关闭面板会恢复原数据格焦点，不进入 SQL、草稿或 IPC 写入路径。

## 当前验证

- Node.js 24.17.0 运行时检查、类型检查和生产构建通过。
- 相关单元测试 7 个文件共 139 项通过。
- SQLite 本机 Electron 验收 1 项通过。PostgreSQL 18.6、MySQL 8.4.11、MariaDB 11.4.13 在 `Server-200` 的专用回环容器中各通过 1 项。每项都回读了 `9007199254740993`、65535 个 `A` 加 CRLF 和 Unicode 尾段、二进制 `00 ff 3c 3e`、空字符串及 SQL NULL，并核对无活动会话和专用资源清理。
- 本机完整单元测试结果为 28582 通过、149 个既有失败、10 个跳过和 24 个未处理错误。失败清单与前一增量基线完全一致，不能把它们计入本增量通过项。标签工作流的 `pnpm test` 结果是阶段版本能否公开生成的最终门槛。

## 发布边界

Windows 安装包、macOS 安装包、源码 ZIP 和 SHA256 清单由同版本标签工作流生成。Windows 未签名，macOS 使用临时签名且未公证。当前未把本机源码验收提升为三个发行安装包均已通过。
