# 结构比较筛选批量选择

结构比较结果表新增“选择当前筛选项”。按钮只提交当前快照中可比较的新增、删除或变化项，保留筛选外已经选择的差异。相同项和不可可靠比较项不会进入同步预览。

选择逻辑在共享辅助层核对快照编号、差异身份和 100 项预览上限。单项勾选及批量选择都在达到上限后拒绝新增，批量操作超额时保留原选择，不产生部分选择。隐藏选择继续显示并可单独清除。

验证范围：结构比较结果逻辑与 React 组件定向测试 28 项，`node scripts/typecheck.mjs`，`git diff --check`。实际数据库、Windows/macOS 安装和完整结构依赖矩阵仍按 M02 的独立验收范围执行。
