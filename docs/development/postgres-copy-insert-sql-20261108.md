# PostgreSQL 表页复制 INSERT SQL

在 PostgreSQL 普通表或分区表的数据网格里，定位一个数据格后点击「复制当前行为 INSERT SQL」，或勾选多行后点击「复制选中行为 INSERT SQL」。多行按原页顺序输出。复制只使用已载入的当前原页，翻页后需要重新选择。视图和被截断的表页不提供入口。

SQL 引用原 schema、表名和完整的普通列，包含布局中隐藏的列。计算生成列由目标表重算，始终生成的标识列使用 `OVERRIDING SYSTEM VALUE` 保留原值。NULL、空文本、二进制和精确数值文本分别保留。所选行含修改或删除草稿、缺少值，或者整批超出上限时，保留原剪贴板。

复制生成普通文本，不发起数据库任务。粘贴执行前需核对目标表、权限、键约束及日期和时区等会话设置。脚本保留原标识值，回放后是否需要调整序列由目标库决定。

## 验证

- macOS arm64 运行时检查、严格类型检查、构建与 474 项定向单测通过。覆盖标识符转义、原页行序、草稿、缺失字段、非规范 Base64 和 SQL 字节上限。
- 两项 macOS Electron 源码用例通过，连接 Server-200 上的隔离 PostgreSQL 18.6。分别验证当前行、勾选行、草稿拒绝、换页失效、视图入口及原有列复制。用例拦截复制事件读取生成文本，未覆盖系统剪贴板。
- 独立连接在事务内以同名空表回放原样 SQL，回读确认超出 JavaScript 安全整数的标识值、高精度小数、带引号和换行的 Unicode 文本、空文本、NULL 和字节。目标表重新计算生成列。回放结束后回滚测试事务，隔离容器、匿名卷和回环转发已清理。

WIN11-TEST 会话无法连接，本轮在 macOS 验证。Windows、安装包和操作系统剪贴板写入待验。
