# SQLite 跨页勾选复制

在可编辑的 SQLite 表里逐页勾选已有记录，再到「SQLite 多页草稿」点击「复制保留页勾选记录为新增草稿」。核对涉及的页号与数量后确认。每条副本按来源页追加，原行与勾选保留。回到对应页可以撤销或重做。

复制使用当前草稿中的字段值。生成列与目录确认的 rowid 别名整数主键由数据库赋值。普通主键和唯一键保留原值，可在副本中调整后再通过「预览 SQLite 修改」集中提交。列内联声明的 `INTEGER PRIMARY KEY DESC` 仍按普通键保留。[SQLite 主键规则](https://sqlite.org/lang_createtable.html#rowid)

跨页使用各原编辑快照的定位摘要去重。快照过期、勾选或来源变化，以及整批超过 SQLite 原提交预算时，不会追加任何副本。

## 验证

- macOS arm64 运行时、严格类型检查、构建和 227 项相关单测通过。覆盖保留已暂存值、逐页撤销、重复定位、拒绝本地新增来源和失效意图。
- 三项 macOS Electron 原生用例使用独立的 SQLite 文件。验证取消、跨页暂存、原勾选、逐页撤销与重做，以及两页集中预览。提交后只新增两行，数据库分配新主键并重算生成列。磁盘回读核对最大 64 位整数和原二进制值。
- 晚期失败用例通过触发器使第二条 INSERT 报错。原五行保持，原生窗口仍可查看两页副本。内联 DESC 主键用例核对 SQL 中保留原键，唯一性冲突后整批回滚。
- 单行复制、多页草稿、跨页删除和跨页填充共六项原生回归通过。原单行复制测试的放弃确认文本已对齐现有工作区，首轮失败的日志和隔离窗口保留。
