# PostgreSQL 语句折叠

打开 PostgreSQL 查询，在「查看 → 编辑器」启用「按 SQL 语句折叠」。使用编辑器左侧箭头收起或展开多行语句。正文首行保留可见。语句末行若同时含有后续 SQL 或注释，也保留该行。

折叠沿用语句导航和执行当前语句的分段器，识别嵌套块注释及 dollar-quote 正文。已有查询会话时使用最近一次会话状态返回的字符串模式。该模式未知时，只有两种模式都得到一致边界才生成语句折叠。超过本地预算或边界无法确认时，编辑器可继续使用普通缩进折叠。

折叠只改变编辑器显示。它不新建数据库会话、不执行 SQL、不修改草稿，并沿用工作区的折叠偏好。

MySQL、MariaDB、SQLite 和 PostgreSQL 在同一个「按 SQL 语句折叠」设置下，也可单独折叠语句内跨行的括号块，包括长 CTE、子查询、函数和表达式。闭括号所在行始终可见，可接着查看同一行的别名、逗号和后续条件。一个起始行同时属于多层时，左侧按钮收起最外层。

括号位置沿用各方言词法，跳过字符串、引用名和注释。PostgreSQL dollar-quote 正文保持独立。MySQL 和 MariaDB 有缓存时使用会话的引号模式。括号边界有歧义或超出预算时，仍保留可确认的整条语句折叠范围。
