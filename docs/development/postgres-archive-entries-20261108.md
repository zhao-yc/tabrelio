# PostgreSQL 自定义归档按条目恢复

在「工具 → PostgreSQL 自定义归档」选择 PGDMP 文件和本机的 `pg_restore`，点击「读取归档目录」，开启「只处理勾选的归档条目」。可按编号、对象类型或名称筛选，逐条勾选或一次勾选全部匹配项。翻页和修改筛选保留已勾选条目，每次最多选择 4,096 项。更换归档或工具、重新读取目录后需要重新勾选。

勾选后可以导出 UTF-8 SQL，或选择已有库或新库恢复。表定义、表数据、索引、约束、Schema 和其他依赖在目录里各有条目，按需一并勾选。恢复按归档原顺序执行。目标库已有所需结构时，可以只勾选数据条目。启用「省略所有者和授权」会继续应用原生工具的对应选项。[PostgreSQL pg_restore 文档](https://www.postgresql.org/docs/18/app-pgrestore.html)

主进程只接受当前文档、归档与工具授权对应目录中的编号。临时清单只含经校验的编号，原生工具离线转换，导出成功后才替换目标文件。直接恢复复用原有的文件事务，回放失败时回滚文件内的变更。若用户选择新建数据库，建库回执独立于文件事务。
