# 多表同步预览筛选

SQLite、PostgreSQL、MySQL 和 MariaDB 的多表同步预览可组合按右侧目标表、插入／更新／删除和记录键筛选。键搜索在界面显示的原值文本中做不区分大小写的包含匹配，支持联合键及精确的 64 位整数文本。

改变筛选会回到结果第一页，保留原预览和已勾选的记录。预览同时显示候选总数、筛选命中数和未在筛选结果中显示的已选数量。清除筛选可恢复浏览全部候选。

启用筛选时，「选中全部匹配项」和表旁的匹配项按钮只影响筛选命中的记录。「选中本页差异」只影响当前页，「取消全部差异」清除所有页的选择。提交计数和确认范围始终覆盖所有已选记录，包括被筛选隐藏的记录。改动勾选时需重新确认目标。

## 验证

2026-11-08 在 macOS arm64 通过 Node.js 24.17.0 运行时检查、严格类型检查、构建、86 项相关单测及 4 项 Electron 窗口测试。SQLite 实测从 125 条候选中组合筛选、处理无匹配结果和保留隐藏的已选项，并在筛选期间确认只写入两条原选记录。PostgreSQL 18.6 实测按键定位末页候选，清除和重新筛选后保留确认文字并提交。MySQL 8.4.11 与 MariaDB 11.4.13 分别作为右侧，独立查询确认只提交筛选后选中的记录。

网络实库使用 Server-200 隔离容器，验收后已清理。Windows 测试会话未连通，Windows 和安装包待验。
