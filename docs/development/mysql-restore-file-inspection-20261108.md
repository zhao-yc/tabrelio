# MySQL 和 MariaDB SQL 文件离线检查

打开「工具 → 执行 MySQL／MariaDB SQL 文件」，选择文件编码及 SQL 文件，再点击「离线检查 SQL」。可以在没有保存连接时使用。需要执行时，选择实际连接及初始数据库后重新选择文件。

检查前选择参考引擎和三段版本号。报告汇总有效语句、结构操作、数据变更及删除或替换，并列出可识别的显式选库、建库和删库操作。通过此列表可核对原生转储是否会按脚本切换数据库。报告只展示最多 20 个不同的库操作、统计及问题序号，结果留在当前窗口。

检查沿用恢复的流式解码和 DELIMITER 扫描，按参考版本展开适用的可执行注释。无法确定引号模式时比较多种词法边界。带库名前缀的对象访问需结合脚本核对，动态 SQL、例程体内操作、目标对象和权限由实际执行判断。单次检查最多统计 50 万条有效语句，未消费的文本超过 8,388,608 个 UTF-16 代码单元时保留已完成的统计。检查与执行确认独立。 [MySQL 注释文档](https://dev.mysql.com/doc/refman/8.4/en/comments.html) · [MariaDB 注释文档](https://mariadb.com/docs/server/reference/sql-statements/comment-syntax)
