# PostgreSQL 多表事务同步

在 PostgreSQL 多表比较窗口，可以将多对表的差异同步到同一个右侧数据库。表对可跨连接、数据库或 Schema，每张右侧表只能出现一次。

## 操作

1. 在单表比较窗口选定两侧连接与数据库，打开「多表比较」，添加至少两对表。表对可使用默认规则或[自定义键与字段映射](postgres-mapped-data-sync-20261108.md)。
2. 在「PostgreSQL 多表同步」选择操作。默认选择插入与更新，删除仅右侧存在的记录需主动勾选。
3. 点击「预览多表同步」。程序重新读取各表，按目标表列出操作和记录键。预览可取消，已有预览可放弃。
4. 输入界面显示的目标确认文字，点击「确认多表同步」。检查事务回执后重新比较。

## 事务范围

每批最多 32 对表，所选差异同时受 100 行及 1 MiB 限制。预览中各表对单独建立快照，提交使用当时读到的来源值。右侧需要满足原单表同步的普通表、列类型和权限要求。启用触发器或被外键引用的目标表会拦截。

程序在一个右侧事务中按限定表名顺序加锁，复核结构、权限及原行版本后才写入。每条语句核对影响行数，更新和插入还会核对回读原值。任一写入失败会整批回滚。提交回执未知时需核对原数据库，程序不会自动重试。MySQL／MariaDB 另有[多表事务同步](mysql-multi-table-sync-20261108.md)。MySQL／MariaDB 的自定义字段映射写入仍待实现。

## 验证

2026-11-08 在 macOS arm64 通过运行时检查、严格类型检查、构建和 39 项相关单测。四项 Electron 窗口测试通过。PostgreSQL 18.6 实库验收覆盖排他锁等待时取消预览、同值更新导致原版本失效、第二张表违反检查约束时整批回滚，以及最终两表四项变更的事务提交。分别独立读回源库和目标库。MySQL 8.4.11、MariaDB 11.4.13 的单表同步及 SQLite 单表和多表同步通过回归。

网络实库使用 Server-200 隔离容器，均已清理。Windows 测试会话未连通，Windows 和安装包待验。
