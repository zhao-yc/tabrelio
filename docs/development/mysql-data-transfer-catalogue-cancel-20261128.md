# MySQL／MariaDB 数据传输目录读取取消

数据传输窗口读取源表目录时现在携带独立任务编号，复用现有独立读取任务和 `query.cancel` 收尾。旧数据库备份入口仍可省略任务编号，保持原调用兼容。目录读取进入忙态后，“停止任务”按钮可准确取消当前传输窗口的读取，不影响其它备份或查询任务。目录加载完成后可按表名筛选、一键全选或清空，超过 32 张表时拒绝全选并要求手动缩小范围；筛选只影响显示，已选隐藏项继续保留。

验证范围：`mysql-database-backup.test.ts` 7 项、`node scripts/typecheck.mjs` 和 `git diff --check`。真实数据库取消、Windows/macOS窗口及安装包验收仍按数据传输矩阵单独执行。
