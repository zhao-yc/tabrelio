# 从选区打开新查询

在 MySQL、MariaDB、PostgreSQL 或 SQLite 查询编辑器内选中一段 SQL，然后右键选择「从选区打开新查询」。MySQL、MariaDB 和 SQLite 的查询工具栏更多菜单以及 PostgreSQL 的查询工具栏也提供该入口。

独立草稿保留选区的空格、换行及原字符，沿用原连接与已确认的默认库。已有 MySQL 或 MariaDB 会话按其实际默认库建立草稿。新标签使用独立会话，SQL 由用户手动执行。原正文、选区和保存来源继续留在原标签。

操作只接受一个非空范围。等待确认时，选区、正文、连接或来源发生变化会结束本次操作。默认库无法确认时可先核对原查询的数据库上下文。

## 验证

- macOS 严格类型检查、构建及 77 项定向测试通过。验证了空白或多选区拒绝、选区移开再移回失效，以及原全文复制回归。
- macOS Electron 离线 2 项通过，覆盖四种数据库的真实菜单或按钮、原文与选区保留、独立草稿及零新增任务和历史。两次早期菜单定位或点击时序失败保留原始记录，按正式菜单交互复验通过。
- macOS Electron 连接 Server-200 独占 MySQL 8.4.11 和 MariaDB 11.4.13，各通过一项实际 `USE` 切库验收。草稿继承切换后的数据库，历史仅保留原查询显式执行的 `USE`。容器、匿名卷和隧道均已清理。
- Windows 测试机不可达，安装包未验。
