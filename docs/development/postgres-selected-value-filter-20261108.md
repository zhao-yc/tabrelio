# PostgreSQL 按勾选行值筛选

在 PostgreSQL 表或视图的记录网格勾选当前页的记录，再点击要取值的字段中的任意单元格。点击「按勾选行值筛选」，核对列名、勾选行数和去重后的原值。空字符串显示为 `""`，文字 `"NULL"` 和 SQL NULL 分开显示。

点「加入筛选草稿」包含这些值，或点「排除勾选值」取补集。新值条件作为一组与当前高级筛选整体做 AND，原分组内的任一满足条件仍保持原关系。若在使用快捷筛选，面板会提示应用时以高级筛选替换它。最后点击「应用高级筛选」，保留排序并从第一页读取匹配记录。其它页的同值记录也会匹配。

排除值时，未勾选 SQL NULL 就保留空值记录，已勾选 SQL NULL 就排除空值记录。仅支持可按原值比较的字段，二进制列不可选。非 NULL 值最多 200 个，每个值最长 4,096 字符，仍须满足高级筛选的总预算。待提交记录草稿会暂时禁用入口。更换勾选或活动格后，原预览须重新打开。
