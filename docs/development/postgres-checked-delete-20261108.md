# PostgreSQL 跨页勾选删除

在 PostgreSQL 可编辑表勾选记录，点「收集本页删除目标」。翻页后可以继续收集。回到某页后，可重新勾选并点「更新本页删除目标」，也可以移除该页或清空全部。当前网格复选框用于本页选择，已收集的目标另行显示累计页数和记录数。

点「删除跨页收集记录」查看原行号与主键，再一次暂存整批。可以一步撤销，或用「预览记录修改」核对 SQL 后明确提交。刷新、筛选、排序或页长变化会结束旧收集。

每批最多收集 100 条，删除目标和当前草稿共享 16 个原页预算。翻页优先请求保留已收集的原令牌。发现令牌失效、过期或多个原页含同一主键时拒绝整批。已暂存更新的记录仍沿用首次修改时的原行版本，撤销整批删除可恢复这些更新。

## 验证

- macOS arm64 的运行时检查、严格类型检查、构建及 37 项相关单测通过。
- Server-200 隔离 PostgreSQL 18.6 的提交和回滚窗口用例通过。两页原主键核对、取消、暂存、一步撤销、切到第三页后重做和集中预览均按预期。提交用例只删除第 2、3 条。回滚用例的触发器核对第一条已在事务中删除，再拒绝第二条。独立查询确认五条原记录与两条待删除草稿都保留。
- 原网格跳转和反选专项通过。完整工作区回归在原 120 秒、零重试门槛下用时约 115 秒，记录 79 项观察。窗口临时配置、隔离容器及回环转发均已清理。
- 首轮用例的表名与客户端限定格式不符，未读到目标表。已保留原报告并清理相应隔离容器，改用规范限定表名后通过。
