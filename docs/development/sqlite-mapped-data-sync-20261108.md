# SQLite 自定义键与字段映射同步

SQLite 可使用异名字段和业务键同步单张表，也可在同一个多表事务中混用默认规则和自定义映射。匹配键可以由多列组成。各键在比较范围内必须非空且唯一，表本身可以没有显式主键。

## 操作

1. 在「比较 SQLite 表数据」选定左右表，展开「自定义匹配键与字段」。添加需要同步的字段对，至少勾选一对「用作匹配键」。
2. 单表同步时，先执行无筛选比较，再勾选要同步的差异。多表同步时，在每对表上选择字段规则，再勾选操作。多表默认选择插入和更新，删除需单独勾选。
3. 核对预览中的目标和记录键，输入目标确认文字并提交。

更新只写入已映射的非键字段。插入只为已映射字段赋值，其余字段由右侧默认值和约束处理。删除会移除右侧整行。右侧生成列可以由 SQLite 自动计算，不能作为写入映射的目标字段。

## 事务范围

预览保留右侧普通列的完整原值。提交在一个右侧文件的写事务内复核原值和匹配键，映射之外的普通列发生并发变更也会中止。文本键按字节匹配，整数和二进制保持原生存储类型。写后复核映射值，遇到并发重复键、约束错误或存储类型转换导致的值变化时整批回滚。

沿用 SQLite 同步的 100 行、1 MiB 选中差异预算和触发器、入向外键保护。筛选结果可继续比较。PostgreSQL、MySQL 和 MariaDB 的映射结果仍用于只读比较。

## 验证

2026-11-08 在 macOS arm64 通过 Node.js 24.17.0 运行时检查、严格类型检查、构建、124 项相关单测及两项 Electron 窗口测试。单表验证无显式主键、异名字段、未映射列并发修改拦截及二进制更新。混合规则的多表事务验证区分大小写的文本与 64 位整数组合键、并发重复键导致整批回滚，以及两表共四项变更的提交。独立读回确认已有记录保留未映射字段，新记录使用右侧默认值并计算生成列，来源未被同步写入。默认主键的单表与多表同步通过回归。

测试使用隔离 SQLite 文件。Windows 测试会话未连通，Windows 和安装包待验。
