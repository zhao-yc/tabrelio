# MySQL 和 MariaDB 跨页勾选删除

在有可靠行键的 InnoDB 表中逐页勾选记录。「多页草稿」会显示各保留页的勾选数，点击「删除保留页勾选记录」可在同一确认框核对页号和数量。确认后，各页记录一次性标为待删除。翻回对应页可以单独撤销或重做，也可以预览全部草稿，核对 SQL 后明确提交。

暂存前核对原缓存、原勾选、各页撤销预算和整批提交预算。不同保留页的变更指向同一原记录时拒绝整批。已勾选的缓存页受原 16 页预算约束，在同一分页范围中不会被自动淘汰。刷新或应用新的筛选或排序会重新建立分页范围。

## 验证

- macOS arm64 运行时、类型检查、构建和 115 项相关单测通过。单测覆盖跨页重复原定位、确认后勾选变化、整批暂存、逐页撤销及缓存淘汰。
- Server-200 隔离 MySQL 8.4.11 和 MariaDB 11.4.13 的原生窗口分别通过。取消确认保留勾选，确认只暂存草稿，切页可撤销或重做。明确提交前独立查询仍有五行，提交回执核对两条 DELETE，最终仅移除第 2、3 条。
- MariaDB 11.4.13 的隔离回滚用例通过。第一条 DELETE 获得服务器确认，第二条由本例触发器拒绝，回执确认事务回滚。独立查询核对原五行均保留，两页待删除草稿仍可查看。
- MySQL 8.0 的原跨页草稿提交恢复回归通过，覆盖提交已成功但回应丢失的场景。临时容器、回环转发与原回归的随机测试库均已清理。

WIN11-TEST 会话未连通，Windows 和安装包待验。此次新增的跨页删除入口覆盖 MySQL 和 MariaDB。
