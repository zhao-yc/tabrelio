# PostgreSQL 跨页逐条编辑

1. 在可编辑的 PostgreSQL 表中逐页勾选记录，点击「收集本页更新目标」。回到原页可更新或移除该页目标。这组目标也可用于「填充跨页收集记录」。
2. 点击「逐条编辑跨页收集记录」，核对页数、来源行号和主键。为不同记录分别填写值。切换记录会保留窗口输入，取消会丢弃本次窗口输入。
3. 点击「暂存整批编辑」。修改进入同一步草稿历史，可整批撤销或重做。通过表页预览核对 SQL 后，再确认事务提交。

窗口可修改各原页共同收集的普通字段。主键和生成列只读，已有草稿的其他字段与首次原行版本会保留。一次最多收集 100 条记录，原值缓存上限为 4 MiB。收集、草稿和撤销历史共用原页名额。页令牌失效后请移除或重新收集，筛选、排序、分页大小或列投影变化后重新收集。同一原记录出现在多个收集页时，需要先调整范围。

## 验证

- macOS arm64 运行时、严格类型检查、构建和 340 项 PostgreSQL 相关单测通过。覆盖页内同号行、首次暂存令牌、未开放字段、恢复原值，以及重复主键和过期原页。
- macOS Electron 连接 Server-200 上的隔离 PostgreSQL 18.6。两项跨页专项验证取消、切换记录保留输入、整批暂存、撤销重做及集中预览。独立连接确认两页文本和精确小数 `9007199254740993.123456789012` 落库，原二进制、NULL 和未勾选记录保持。
- 失败用例通过触发器确认第一条 UPDATE 已执行，再拒绝第二条 UPDATE。独立连接确认整批回滚，窗口保留两条草稿。
- 原单页逐条编辑、跨页填充和跨页复制共六项实库回归通过。原单页用例的两次早期失败分别来自按旧网格值定位、以及事务确认前回读。改为按精确主键定位并等待提交确认后，回归通过。失败日志与隔离窗口保留，失败实库回读并留存结果后清理。所有本轮隔离容器、回环转发和匿名卷已清理。

WIN11-TEST 会话无法连接，本轮在 macOS 验证。Windows 和安装包待验。
