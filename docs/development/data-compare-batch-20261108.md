# 多表数据比较

从 SQLite、PostgreSQL 或 MySQL／MariaDB 表数据比较窗口进入多表比较，可以按表映射核对两个范围。该流程对应 Navicat 数据同步中的表映射和按表查看差异步骤。[Navicat 16 官方手册 Data Synchronization](https://www.navicat.com/manual/pdf_manual/en/navicat_16/win_manual/navicat_en.pdf#page=181)

## 操作

1. 在单表比较窗口选择左右连接。PostgreSQL、MySQL 和 MariaDB 还需要分别选择数据库。点击「多表比较」。已选的有效表对会带入映射列表。
2. 点「匹配同名表」生成建议，或逐对选择表并点「添加映射」。同一侧的表在每批中最多使用一次。相同连接和数据库中的异名表可手动映射。
3. 点「比较所选表对」。窗口逐对显示相同、仅左侧、仅右侧、字段值不同的行数，或显示该表对的错误。其它表对继续比较。点「停止批次」可取消当前读取并保留已完成的结果。
4. 点「打开表对」，重新比较后可分页审阅逐行原值。如果需要写入，沿用单表同步的勾选、预览和确认步骤。返回批次时该表对的旧计数清除，其余结果保留。

## 范围

每批最多 32 对表。自动建议超过预算时，可手动选择较小批次。名称按准确大小写匹配。PostgreSQL 优先匹配准确限定名。两侧各自只有一个同名表时，也会建议跨 Schema 映射。

批次逐对读取完整表，沿用单表主键、字段和读入预算。各表对可能来自不同时间的快照。批次不带单表筛选、不生成逐行同步快照。临时映射保留到退出多表窗口为止，也可以命名保存并重复载入。[多表比较方案](data-compare-batch-profiles-20261108.md)支持整批换向。[批次级键与字段映射](data-compare-batch-column-mapping-20261108.md)支持为每对表单独选择比较字段和匹配键，并带入单表回查。跨表事务同步仍待实现。

## 验证

2026-11-08 在 macOS arm64 通过运行时检查、严格类型检查、构建、9 项相关单测和 3 项源码 Electron 窗口测试。SQLite 验证跨文件同名及异名映射、无主键表失败后的继续处理，以及单表回查。PostgreSQL 18.6 验证跨库汇总，并在真实排他锁下取消当前读取，后续映射未派发。MySQL 8.4.11 和 MariaDB 11.4.13 验证跨引擎汇总，并独立读回两侧确认没有变化。各窗口还回归了原来的单表比较和同步。

网络实库运行于 Server-200 上的隔离容器，测试结束后已清理。Windows 测试会话未连通，Windows 与安装包待验。
