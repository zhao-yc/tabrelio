# 表页原主键查询草稿

在 MySQL、MariaDB、PostgreSQL 和 SQLite 的有主键表页，选择一个数据格或勾选本页记录，然后点击「打开原主键查询草稿」。有勾选时使用全部勾选行。MySQL 和 MariaDB 在「更多 → 生成查询」中提供入口，PostgreSQL 和 SQLite 在表格上方提供入口。SQLite 的只读普通表也可使用。

新标签沿用原连接和数据库，正文与「复制原主键查询 SQL」生成的 SELECT 相同。键值来自当前已载入的原行。可以编辑正文，再手动运行。打开草稿只写入工作区设置。

表页重新核对当前页与选择后才打开查询。超过标签上限、主键值不完整或 SQL 生成失败时，保留原表页并提示原因。

## 验证

- macOS 严格类型检查、构建及 445 项定向测试通过。
- macOS Electron 的 7 项原生测试通过。SQLite 使用本机隔离文件，PostgreSQL 18.6、MySQL 8.4.11 和 MariaDB 11.4.13 使用 Server-200 独占测试库。已核对隔离容器、匿名卷和隧道清理。
- 四种数据库均在可编辑查询标签中核对了完整 SQL、原连接和数据库。打开草稿未新增查询任务或历史，也未调用复制操作。PostgreSQL 和 SQLite 保留未提交的行修改。SQLite 干净表页切回时沿现有机制重读，需重新勾选。
- Windows 测试主机不可达。本轮验证范围为 macOS 源码和 Electron，未验安装包。
