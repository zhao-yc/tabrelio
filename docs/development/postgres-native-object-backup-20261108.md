# PostgreSQL 原生指定对象备份

打开「工具 → PostgreSQL 数据库备份」，选择来源连接和数据库，将备份范围切换到「指定表及关系」。支持按完整限定名或类型筛选，在不同 Schema 中勾选表、分区、视图、物化视图、外部表和序列。每次最多选择 64 项，筛选和翻页保留勾选。支持纯文本 SQL 和 PostgreSQL 自定义归档，也可选择仅结构或仅数据。

仅数据模式保留所选本地表、叶子分区和序列。备份分区表时，按需单独勾选子分区。视图、物化视图和外部表使用原生工具的定义导出行为。目录列出当前角色有读取权限的独立对象，扩展提供的对象请随扩展准备。恢复前请在目标库准备 Schema 和其他依赖，包括未选的父分区、被引用表、类型、外部服务器或所需的大对象。序列等附属对象随原生工具的依赖处理规则导出。[PostgreSQL pg_dump 文档](https://www.postgresql.org/docs/18/app-pgdump.html)

文件授权绑定连接、数据库、对象范围、内容和格式。工具以独立参数传入逐段引用的限定名，支持包含点号、引号和通配符的名称。生成前在导出的快照中核对对象身份，快照结束后重新读取目录，发现对象替换或读取权限丢失时保留原目标文件。

## 验收记录

2026-11-08，macOS arm64 源码通过运行时检查、类型检查、构建和 63 项相关单测。通过 Server-200 隔离 PostgreSQL 18.6 实例和同版原生工具运行 7 项 Electron 实库测试，无失败、跳过或重试。

新用例将跨 Schema 的表、视图和序列恢复到预建目标库，并把仅数据 SQL 回放到另一个已有结构的库。独立连接核对了 Unicode、NULL、BYTEA、序列值 `9007199254740997`、视图行数及两个未选表缺席。文件授权范围变化和开始前同名替换均被拦截，原文件字节保留。其余用例回归整库、指定 Schema、单表、多表、归档条目和 SQL 文件恢复，包括 SSH、严格 TLS 和取消。

隔离容器、测试会话、隧道和临时目录已核对清理。WIN11-TEST 当时不可达。Windows、安装包、其他 PostgreSQL 版本，以及本功能的分区、物化视图和外部表恢复组合待验。
