# SQLite 跨页勾选填充

在可编辑的 SQLite 表里逐页勾选记录。页号旁显示该页的勾选数。

1. 在「SQLite 多页草稿」点「填充保留页勾选记录」，核对页号、各页数量和合计数量。
2. 勾选需要修改的字段，选择类型并输入统一值。生成列不可选。仅选择本地新增记录时可选 DEFAULT。
3. 点击「暂存 SQLite 批量填充」。暂存保留勾选，每页可独立撤销或重做。
4. 点击「预览 SQLite 修改」，核对所有保留页的 SQL 后明确提交。冲突时整个事务回滚，保留草稿供核对。

各页始终使用原 SQLite 快照与本地记录身份。弹窗打开后，原页、勾选或编辑代次变化会使本次填充失效。整组变更与已有草稿共用 SQLite 提交预算，全部校验通过后才暂存。

## 验证

- macOS arm64 的运行时、严格类型检查、源码构建和 215 项相关单测通过。覆盖逐页撤销、仅后台有勾选、来源失效、合计预算与等值重填。
- 修正填充来源对 SQLite 原生主键标记的识别。首轮原生回归触发了原主键快照的字段数量校验，修正后添加了主键来源回归断言。
- macOS Electron 使用独立的临时合成 SQLite 文件。提交用例核对取消、暂存、各页勾选、逐页撤销和集中预览。独立连接确认仅所选两行的两个字段更新，`9007199254740993` 精确以 INTEGER 存储，未选择的 BLOB 和其他记录原样保留。
- 回滚用例在预览后从独立连接改动第二页的一行。提交回执确认整批回滚，磁盘只保留外部修改，窗口仍保有两页填充草稿。原单页填充、跨页删除及多页草稿回归也通过。
- 长表单使用应用统一的滚动内容区和固定底栏，原生用例检查暂存按钮仍在视口内。
