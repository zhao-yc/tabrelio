# SQLite 跨页勾选导出

在表或视图中勾选记录，点击网格下方的「收集本页勾选」。切换到其他页后可继续收集，底部显示累计页数和记录数。重新收集同一页会替换该页的记录。需要移除某一页时，在该页取消全部勾选并点击「更新本页收集」。也可以点击「清空已收集记录」一次清除。

点「导出已收集记录」可预览列和样本，再从原文件窗口选择格式、编码和保存位置。文件按页码及页内显示顺序写出，只包含收集时的可见列及原值，沿用现有行数、单元格与文件大小预算。收集与预览无需重新执行查询。

收集保存在当前标签的内存中。刷新、应用新筛选或排序、修改页长或可见列顺序、成功提交记录或导入后会清除。存在记录草稿时需先处理草稿。各页使用各自读取时的值，数据在不同次读取之间变化时，同一记录可能移动到另一页。跨页批量编辑继续沿用原草稿工作区。

## 验证

- macOS arm64 的运行时检查、严格类型检查与构建通过。8 个相关单测文件共 163 项通过，覆盖页序、单页替换和移除、原值独立快照、可见列和来源校验。
- 5 项原生窗口测试通过。新用例覆盖可编辑表收集、标签隔离、只读视图跨页收集、单页替换与移除，以及刷新清除。使用原文件授权和后台写入，独立读回 JSON 确认只有第 2、101 条，源 SQLite 文件字节一致。打开预览前后没有新增数据任务。
- SQLite 原全量导出九种格式和多页草稿事务的两项独立窗口回归通过。
