# CSV 按记录范围导入

MySQL、MariaDB、PostgreSQL 和 SQLite 的现有表导入及新表向导均支持选取 CSV 记录范围。

1. 选择编码、分隔符和字段名开关。已有字段名时可填写「字段名记录号」，默认第 1 条。
2. 填写「首条数据记录号」和「最后数据记录号」。例如第 1 条为说明，第 2 条为字段名，第 3 条为注释，第 4 至 20 条为明细，第 21 条为汇总，依次填 2、4、20。首末记录都包含在范围内。
3. 默认从字段名之后开始读，无字段名时从第 1 条开始。末尾留空则读到文件结束。无字段名时，按第一条选中数据的列位置建立映射。
4. 核对样本、映射和预检结果，再确认写入。修改范围会撤销先前的映射及预检。支持保存导入配置的入口可复用该范围。

指定非默认范围后，从 1 开始按逻辑记录编号。空白记录计数，双引号包围的字段内换行仍属于同一条记录。范围外记录可有不同列数，整个文件仍须符合所选分隔符及引号语法。使用默认设置的旧配置沿用原来的空行处理。

PostgreSQL 的「原生 COPY」将选中的 UTF-8 记录按原字节发送，并核对文件身份和 COPY 回执行数。未加引号的空字段为 NULL，带引号的空字段为空字符串。「tabrelio CSV」使用 `\N` 表示 NULL，空字段为空字符串，可用 UTF-8、UTF-16 LE 和 GB18030。新表沿用向导原有的 tabrelio CSV 解释。

整文件来源核验仍检查全部原始字节。新表向导锁定初次扫描的范围，建表与写入数据仍分开确认。

字段名和首末数据记录设置参考官方手册。[Navicat 导入向导](https://www.navicat.com/manual/online_manual/en/navicat_18/win_manual/import_wizard.html)
