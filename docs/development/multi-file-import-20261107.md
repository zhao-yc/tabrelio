# 向同一张表导入多个文件

在 MySQL 或 MariaDB 的 InnoDB 基本表打开「导入数据」。选择 CSV、TXT、JSON 或 XML，核对编码及文件解释，再点击「多文件导入」。

1. 点击「选择并扫描多个文件」，用系统文件对话框一次选择 2 至 16 个文件。
2. 核对扫描后的文件顺序、记录数和样本。所有文件共用格式、编码、记录范围和字段设置，源字段集合须一致。有字段名的文件可以采用不同列顺序。
3. 核对「共用字段映射」。可以按名称、按列顺序批量映射，也可以逐项设置。点击「预检全部文件」后逐份确认类型、记录数、源指纹和目标结构。
4. 核对合计行数，再点击「确认整批导入」。数据库确认提交后，界面显示文件数和已提交记录数。

本次批次把全部选中文件按清单顺序写入同一个事务，执行新增。预检后修改映射须重新预检。文件任一部分变化、记录数变化或写入失败时，客户端尝试回滚整批。遇到提交结果未知时，通过目标表核对实际数据再决定后续操作。批次授权只允许一次提交。

选择「Excel（XLSX）」后也可点击「多文件导入」。通过「选择多个 Excel 工作簿」选文件，为每本工作簿选择工作表，填写共用标题行、首末数据行和文本协议，再完整扫描。字段名称可相同而排列顺序不同。标题行填 0 时可按位置手动映射。预检及提交沿用每本所选工作表并逐份核对指纹。

## PostgreSQL

在现有表打开「导入数据」，设置格式后点击「选择多个文件」。可一次选择 2 至 16 个同结构的 CSV、TXT、JSON 或 XML 文件。批次内共用格式、编码、记录范围和字段映射。界面列出每份文件的记录数，样本取自第一份文件。字段名唯一且非空时，可用不同的列顺序。空名和重名的原生 CSV 按相同列序映射。

原生 CSV 逐份扫描 UTF-8 字节和所选记录列数，按各文件的实际列序把原字节发送给 COPY。未加引号的空字段写入 NULL，带引号的空字段写入空字符串。执行前后核对文件身份、大小和修改时间，并核对 COPY 返回的行数。tabrelio CSV、TXT、JSON、XML 逐份完整扫描源字段及原字节指纹，在提交前重新核对。目标类型和约束在数据库执行时校验。

确认后可整批追加，或使用已映射的匹配键执行跳过已有、新增或更新、仅更新已有。按键导入会用同一份暂存表检查所有文件，两个文件出现相同的源键也会导致整批回滚。

导入 Excel 时，选择「Excel（XLSX）」和「选择多个 Excel 工作簿」。逐本选择工作表，填写共用的标题行、首末数据行和文本协议，再点击「完整扫描工作表」。确认窗口列出文件名、工作表名和记录数。有标题时按相同的字段名匹配，允许调整列顺序。标题行为 0 时按列位置手动映射。读取工作表目录、扫描和正式导入之间会核对工作簿的字节指纹。

## SQLite

在主库的现有普通表打开「导入 SQLite 表数据」，设置 CSV、TXT、JSON 或 XML 后点击「选择多个 SQLite 导入文件」。每批可选择 2 至 16 个同结构文件，随后点击「检查 SQLite 导入文件」。界面显示每份文件的记录数，样本取自第一份文件。具有字段名的文件可以采用不同列顺序。

设定共用的字段映射和 SQLite 动态类型，再点击「预检 SQLite 全部导入记录」。检查按所选顺序逐份核验文件，诊断中的记录号沿整个批次累计。预检通过后输入界面显示的准确库表名以确认写入。全部文件在同一个 SQLite 事务中新增，第二份文件违反约束时，第一份已处理的记录也会回滚。源文件身份或原字节变化会阻止提交。

选择「Excel（XLSX）」也可多选工作簿，每本单独选工作表，整批共用标题行、数据范围、文本协议和 SQLite 动态类型映射。检查结果逐份显示工作表名和记录数。读取目录后替换工作簿须重新选择。预检后替换工作簿会阻止写入，写入期间发生文件变化或约束失败会回滚原事务。

各入口均以同一张现有表为目标。逐文件行范围和映射、不同目标表仍待接入。

官方导入向导支持添加多个源文件。[Navicat 导入向导](https://www.navicat.com/manual/online_manual/en/navicat_18/win_manual/import_wizard.html)
