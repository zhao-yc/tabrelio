# JSON 导入配置的完整字段核验

MySQL 和 MariaDB 的普通 JSON 导入默认显示样本。保存配置前，点击「扫描全部 JSON 字段」可检查整个文件并补齐来源字段。已有的有效映射会保留，后续记录才出现的字段可以单独核对。数据网格仍只显示有限样本。

应用 JSON 配置时会自动重新扫描文件，并比对全部源字段及当前可写目标列。第 21 条或之后新增、改名、缺失的字段同样会影响兼容性。若旧配置只保存了样本列，可点击「使用样本预览」，然后完整扫描并更新配置。

完整扫描复用有界文件检查，最多收集 1000 个源字段。更换文件或切回样本预览会取消旧扫描。字段核验发生在扫描时，检查全部记录值和确认写入仍分别由导入预检及提交完成。
