# PostgreSQL 跨页勾选填充

在可编辑的 PostgreSQL 表中逐页勾选记录，点击「收集本页填充目标」。回到该页可更新或移除它的目标。点击「填充跨页收集记录」可核对页号、每页数量和总数。

选择各原页共有的可编辑列并设置统一值，可一次设置多个字段。点击「暂存整批填充」后保留收集范围，可用「撤销整批填充」或重做操作恢复整组草稿。点击「预览记录修改」核对 SQL 后再明确提交。

填充使用各原页令牌，已有更新保持首次定位与未选字段。跨页收集支持最多 100 条记录，字段原值缓存上限为 4 MiB。填充、删除收集与草稿共享 16 个原页名额。切换筛选、排序、每页条数或列投影时重新收集。原页过期或被释放后，旧目标不能继续暂存。

## 验证

- macOS arm64 运行时、严格类型检查、源码构建与 27 项相关单测通过。单测覆盖原快照和已有字段保留、等值跳过、重复主键、失效页和缓存预算。
- macOS Electron 连接 Server-200 上的隔离 PostgreSQL 18.6。原生提交用例核对各页范围、取消、暂存、撤销、再次翻页、重做和集中预览。独立连接确认只有所选两条记录的文本和 12 位小数更新，未选的二进制列和其它记录保持原值。
- 原生回滚用例的第二条 UPDATE 被触发器拒绝。触发器核对第一条更新已在事务中生效，随后独立连接确认五条原记录均已恢复，原窗口保留两条草稿。
- PostgreSQL 跨页删除的原生提交与回滚回归通过。四项原生用例串行、零重试，临时容器、回环转发和两只匿名卷已清理。

WIN11-TEST 会话无法连接，本轮在 macOS 完成源码窗口验收。Windows 和安装包待验。
