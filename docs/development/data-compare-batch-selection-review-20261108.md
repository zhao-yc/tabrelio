# 多表同步核对已选差异

在 SQLite、PostgreSQL、MySQL 和 MariaDB 的多表同步预览中，勾选候选后点「核对已选差异」。汇总表按右侧目标表列出已选的插入、更新和删除数量。下方只显示已选记录，包括当前筛选隐藏的记录。每页显示 25 条，可以展开记录核对左右字段原值。

再次点「核对已选差异」回到原筛选的第一页，继续调整勾选。切换浏览方式保留勾选和已输入的确认文字，修改勾选时需重新确认。核对期间也可直接提交，仍须满足原事务预算和目标确认要求。

## 验证

2026-11-08 在 macOS arm64 通过 Node.js 24.17.0 运行时检查、严格类型检查、构建、86 项相关单测和 4 项 Electron 窗口测试。SQLite 核验混合操作逐表计数、125 条已选差异分页及超限禁止提交，并从核对清单展开筛选隐藏记录的字段值。独立读回确认只写入两张表各一条勾选记录。PostgreSQL 18.6、MySQL 8.4.11 与 MariaDB 11.4.13 均验证从无匹配的筛选进入核对清单，保留确认文字并只提交勾选的一条记录。

网络实库使用 Server-200 隔离容器，验收后已清理。Windows 测试会话未连通，Windows 和安装包待验。
