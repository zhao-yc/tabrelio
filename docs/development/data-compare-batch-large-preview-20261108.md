# 多表同步大批差异分页预览

SQLite、PostgreSQL、MySQL 和 MariaDB 的多表同步可在一份预览中核对最多 2,000 条候选差异。候选证据和字段详情共用 8 MiB 预算，各数据库原有的表读取预算继续适用。

每页显示 25 条差异，可逐页浏览或直接跳到指定页。可以逐行勾选，也可以选中当前页或整张表。翻页保留选择，操作计数与确认文字覆盖所有页的已选记录。超出单次提交预算时，预览从空选择开始。

单次事务仍最多提交 100 条差异及 1 MiB 写入证据。超出时，预览会提示减少选择，确认入口暂不可用。成功提交后可重新预览剩余差异。提交使用原预览的可信行，仍按原有事务和并发复核规则执行。

## 验证

2026-11-08 在 macOS arm64 通过 Node.js 24.17.0 运行时检查、严格类型检查、构建、85 项相关单测和 4 项 Electron 窗口测试。四种引擎均使用 125 条候选实测直接跳至末页并提交所选行。SQLite 另验跨页保留两张表的选择，以及选中超过 100 条时禁用提交。独立查询确认 SQLite 只写入两条跨页记录，PostgreSQL 18.6、MySQL 8.4.11 和 MariaDB 11.4.13 分别只写入末页勾选的一条记录。分页控件的最终样式在 SQLite 原生窗口复验。

网络实库使用 Server-200 隔离容器，验收后已清理。Windows 测试会话未连通，Windows 和安装包待验。
