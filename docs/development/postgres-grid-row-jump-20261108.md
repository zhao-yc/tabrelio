# PostgreSQL 表页跳到行

在 PostgreSQL 普通表或只读视图的记录网格上方，点击「跳到行」。焦点在网格内时也可按 Ctrl＋G，或选择原生菜单「编辑 → 跳到行／行列」。输入本页从 1 开始的行号并按 Enter，网格滚动并聚焦对应行的当前数据列。尚未选择数据列时，定位到第一个可见数据列。

行号按本页显示顺序计算。筛选或排序后的第一页与后续页均从 1 开始。翻页、刷新或切换列布局时，旧输入会关闭。跳转保留当前勾选和已暂存草稿，过程中只使用已经加载的记录。正在编辑单元格时，快捷键保留在原输入框。

按 Esc 取消并回到「跳到行」按钮。查找面板同时打开时，取消跳转仍保留查找面板。
