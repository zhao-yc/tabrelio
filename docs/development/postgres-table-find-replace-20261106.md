# PostgreSQL 表页查找与替换

在表或视图的记录页点击「查找本页」，或按 `Ctrl/⌘+F`。可按数据、字段名或 SQL NULL 查找，并限制到一列。文字查找支持区分大小写、整格匹配和高亮所有匹配。按 `F3` 或 `Shift+F3` 在匹配位置间前后移动。结果按本页行和可见列顺序定位，包括已有的更新草稿。待删除记录会跳过。 [Navicat 查找与替换手册](https://www.navicat.com/manual/online_manual/en/navicat_18/win_manual/data_rdbms.html#sort--find--replace-records)

在可更新的普通表点击「替换本页」，也可按 `Ctrl+H`（Windows）或 `⌥+⌘+F`（macOS）。查找后选择预览替换当前处或全部匹配。替换支持 PostgreSQL `text`、`character` 和 `character varying` 字段。替换文字默认按字面使用，空输入可移除非空匹配。数字、日期等匹配仍可导航。字段名、SQL NULL、生成列和字节不参与文字替换。

检查替换前后的值，确认加入草稿。已有行的其他暂存字段继续保留，替换沿用该行首次暂存的原行版本。当前页、可见列或草稿一旦变化，旧预览即失效。点击「预览记录修改」检查整批 SQL 和字段，然后明确确认提交。

## 正则与捕获组

选择「数据」并勾选「正则表达式」后，可以使用 JavaScript Unicode 正则。直接输入表达式，大小写和整格边界由面板选项控制。零宽匹配可插入文字。替换一处后，从实际替换结果之后继续定位。字段名和 SQL NULL 查找仍使用各自的原有规则。

勾选「展开捕获组」后，替换文字才按 JavaScript 替换规则解释。例如用 `(?<前缀>[A-Za-z]+)([0-9]+)` 查找 `Foo12`，用 `$2-$<前缀>` 生成 `12-Foo`。未勾选时会写入原样的 `$2-$<前缀>`。查找和预览各在本地可终止线程运行，单次限时 1.5 秒，超时或超出替换预算时保留已有草稿。

## 替换预览的可见操作

替换预览展开后会把「加入草稿」滚入面板可视区。窗口较矮或查找工具栏换行时，仍可直接点击暂存。面板继续保留替换前后的值供核对。预览展开时保持现有焦点，实际写库仍需原来的 SQL 预览及确认。
