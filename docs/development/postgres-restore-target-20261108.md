# PostgreSQL 恢复目标预检

「执行 PostgreSQL SQL 文件」和「恢复 PostgreSQL 自定义归档」在选择目标后自动只读核对。面板显示当前数据库或维护库、待创建的新库、实际角色、服务器版本及连接库编码。服务器通过 TCP 接收时也显示实际地址。现有库可展开最多八个可访问 Schema 中的关系样本，便于区分名称相近的目标。

只读连接、模板库、缺少建库权限及已占用的新库名会阻止恢复。现有库包含对象时仍可按需执行。预检用于确认连接目标和基本状态，文件里的对象依赖和具体对象写入权限仍由 PostgreSQL 在执行时核对。 [PostgreSQL 数据库目录](https://www.postgresql.org/docs/18/catalog-pg-database.html) · [CREATE DATABASE 文档](https://www.postgresql.org/docs/18/sql-createdatabase.html)

预检授权绑定当前窗口、连接配置和目标，五分钟内有效。执行时会在实际连接上复核服务器、角色和数据库身份。新建恢复会再次检查维护库和名称，创建成功后再核对新库身份。同名替换或配置变化后，需要点击「重新核对目标」。文件执行前发现目标已变化时，回执显示「文件执行未开始」。建库成功后若文件回滚，保留已创建的库并单独显示建库回执。
