# 将 SQLite 的多个对象导出到同一本 Excel

在 SQLite 连接的 `main` 库打开表或视图列表，点击「导出多个对象到 Excel」。在窗口中搜索并勾选 2 至 64 张表或视图，核对页签名称和顺序，再选择保存位置并开始导出。勾选顺序决定工作表顺序。Excel 不允许的字符会替换，过长的名称会截短，重名会加序号。

每个对象输出全部数据和可读取的字段，空表或空视图保留标题。任务使用独立的只读连接，并在同一个 SQLite 快照内依次读取各对象。数字使用文本保留精度，NULL 和二进制沿用 tabrelio 可逆文本协议。重新导入时选择该协议即可恢复相应值。

所有工作表都写完、数据库连接正常退出且暂存文件校验完成后，才替换目标文件。期间取消或任一工作表读取失败时，原目标文件保持原样。文件与工作表仍受 Excel 行数、单元格长度和工作簿体积限制。

当前入口覆盖同一 SQLite 主库中的表和视图。逐对象字段和筛选设置、网络数据库的同类入口另行覆盖。[Navicat 导出向导](https://www.navicat.com/manual/online_manual/en/navicat_18/win_manual/export_wizard.html)
