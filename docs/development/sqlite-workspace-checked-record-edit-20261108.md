# SQLite 跨页逐条编辑

1. 在可编辑的 SQLite 表里逐页勾选记录，再到「SQLite 多页草稿」点击「逐条编辑保留页勾选记录」。
2. 核对各页数量和当前记录的来源页。可用字段表单、整行 JSON 或记录树分别修改每条记录。切换记录只保留窗口输入，取消会放弃这次整组输入。
3. 点「暂存全部 SQLite 勾选记录」。各页的修改分别进入原页草稿，勾选保留。回到原页可独立撤销或重做。
4. 点「预览 SQLite 修改」，核对所有有修改的保留页，再确认提交。任一原记录冲突时整批回滚。

窗口只使用已保留的有效页。每条记录绑定原编辑快照及页内身份。不同页勾选了同一条原记录时，请调整勾选后重试。来源失效、字段值非法或整组超出 SQLite 草稿预算时，各页草稿不会被部分暂存。生成列只读，已勾选的本地新增记录可保留未设置字段的数据库默认值。

## 验证

- macOS arm64 运行时检查、严格类型检查、构建和 179 项相关单测通过。覆盖页内同号记录、后台页勾选、重叠定位、后页失败时整组不变、分组预览及逐页撤销。
- 两项 macOS Electron 源码用例使用独立合成 SQLite 文件。验证切换记录保留各自输入、取消、整数越界、无数据库任务的草稿暂存、保留勾选和逐页撤销重做。
- 提交用例直接读取数据库文件，确认两页各自的文本与整数 `9007199254740993` 精确落盘，其余字段和记录保持。回滚用例在预览后从另一个 SQLite 连接修改第二条目标，确认第一条更新也回滚，并保留两页草稿供核对。
- 当前页批量表单、跨页填充、跨页删除及多页草稿共六项 macOS 原生回归通过。
