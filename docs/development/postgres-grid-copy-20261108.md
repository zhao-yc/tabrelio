# PostgreSQL 表页复制

在普通表或只读视图的网格上方，点击「复制（含列名）」。勾选记录时按本页显示顺序复制其可见列，未勾选时只复制当前格及其列名。列名只进入普通文本，tabrelio 内部粘贴读取的数据行不带表头。

选中数据格后点击「复制当前列」，复制本页这一列，包括尚未滚动显示的行。已有勾选时只复制这些行，输出不带列名。两个入口都沿用当前网格的排序和可见列。

已暂存的值按网格显示复制，SQL NULL 和二进制在内部格式中保留类型，大整数和小数保留原文。待删除行沿用普通复制的原值规则。选择范围含待应用的 DEFAULT 时，整次复制会被拒绝，并提示等待服务器生成实际值。复制使用已加载的数据，不会重新查询或写入数据库。
