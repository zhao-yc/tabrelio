# 将 PostgreSQL 的多个对象导出到同一本 Excel

在 PostgreSQL 的数据库对象列表打开「表」或「视图」，点击「导出多个对象到 Excel」。可跨 schema 勾选同一数据库中的 2 至 64 个对象。窗口显示完整限定名及对应的工作表名，勾选顺序决定工作表顺序。页签以对象名生成，重名追加序号，Excel 不允许的字符会替换。

任务在同一个可重复读只读事务中依次读取各对象，用有界游标流式输出全部可读取的行与字段。支持普通表、分区表、视图及已填充的物化视图。权限、行级安全和视图定义按原连接角色执行。空对象保留标题，64 位整数及高精度数值按文本输出，NULL 和二进制沿用 tabrelio 可逆文本协议。

全部工作表读完并确认游标、事务和连接结束后，才原子替换目标文件。读取中取消、对象变化或单表导出失败时，不发布本次文件。外部表和逐对象筛选或投影仍待接入。[Navicat 导出向导](https://www.navicat.com/manual/online_manual/en/navicat_18/win_manual/export_wizard.html)
