# MySQL 和 MariaDB 跨页勾选复制

在有可靠定位键的 InnoDB 表中逐页勾选已有记录。打开「多页草稿」并点击「复制保留页勾选记录为新增草稿」，核对每页的数量后确认。

副本追加到各自来源页，使用原记录当前的已暂存字段值。自增列和生成列由数据库处理，其他主键和唯一键随原值复制，预览前可按需修改。原勾选保留，返回任一页可以单独撤销或重做该页的复制。

所选原页必须仍然有效，记录值必须完整，不能跨页重复选择同一原记录。全组选区和现有草稿都通过原有预算后才追加副本。通过「预览并提交」核对全部 SQL，再明确确认写入。

## 验证

- macOS arm64 运行时、严格类型检查、构建和 192 项相关单测通过。单测覆盖勾选来源、重复定位、整组预算、已暂存值、复制键标记和逐页撤销。
- macOS Electron 连接 Server-200 上的隔离 MySQL 8.4.11 和 MariaDB 11.4.13。两项提交用例都核对了确认框页号、取消、原勾选、逐页撤销与重做。暂存及预览时独立连接仍读到原五行。确认提交后只新增两行，数据库分配新的自增键并重算生成列，精确小数、二进制和 NULL 按源记录保留。
- 两个数据库的第二条 INSERT 失败用例均通过。回执记录首条已获服务器确认，随后整批回滚。独立连接确认原五行保持，窗口仍保留两页新增草稿。四项原生用例串行、零重试，临时容器和回环转发已清理。
