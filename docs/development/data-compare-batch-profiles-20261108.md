# 多表比较方案与换向

SQLite、PostgreSQL、MySQL 和 MariaDB 的多表比较窗口可命名保存左右连接、数据库和有序表映射。适合反复核对同一组表。

## 使用

1. 建立表映射后，展开「多表比较方案」，输入名称并点「另存为新方案」。已有方案可应用、更新、改名或删除。
2. 下次进入对应数据库的比较窗口，直接打开「多表比较」。可以从空白范围选择并应用方案。载入会核对当前两侧目录，成功后恢复映射，清空旧比较结果。确认范围后点「比较所选表对」。
3. 点「交换左侧与右侧」，调换两个范围及每对表的方向，映射顺序保持。旧结果会清空，重新比较后才会显示新方向的差异。要保留反向配置，可另存为新方案。

## 边界

单表与多表方案分开列出，同名可以共存。SQLite 和 PostgreSQL 各自独立，MySQL 和 MariaDB 共用同一组。每组最多保存 32 项，每项最多 32 对表。方案字段只包含配置及本机连接校验信息，比较结果、任务和同步确认均不保存。

连接已移除、路由配置变化或目录缺少某张表时，应用会报错并保留当前映射和结果。请核对两侧配置后更新方案。批次比较仍是只读，逐行同步需进入某一表对重新比较、预览和确认。

## 验证

2026-11-08 在 macOS arm64 通过运行时检查、严格类型检查、源码构建、11 项相关单测及 3 项 Electron 窗口测试。SQLite 跨文件用例验证从空白范围载入三个映射、换向后单侧计数互换，以及目录对象改名时保留现有结果。PostgreSQL 18.6 验证跨库载入。MySQL 8.4.11 与 MariaDB 11.4.13 验证共享方案保存、换向和载入，独立读回确认批次比较未写库。既有单表方案和同步流程通过回归。
