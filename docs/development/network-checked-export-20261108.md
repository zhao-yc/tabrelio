# 网络数据库跨页勾选导出

MySQL、MariaDB 和 PostgreSQL 表页可逐页勾选记录，点「收集本页勾选」保留当时的可见列与原值。返回原页后可点「更新本页收集」替换该页，全部取消勾选后更新会移除该页。MySQL 和 MariaDB 返回缓存页时可能恢复原复选框，更新前可直接调整这些勾选。

「导出已收集记录」打开文件预览，按页码与页内显示顺序写出。收集与预览使用已经载入的原值，沿用文件导出预算。未提交的记录草稿须先处理。刷新、表目标或连接变化、筛选、排序、页长及可见列范围或顺序变化会撤销旧收集。收集保存在当前标签的内存中，各页保留各次读取时的内容。

## 验证

- macOS arm64 的运行时、类型检查、构建和 98 项相关单测通过。
- Server-200 上的 PostgreSQL 18.6、MySQL 8.4.11 和 MariaDB 11.4.13 隔离实库分别通过。真实窗口从两页收集并替换第一页，后台文件写入后独立读回 JSON，精确核对记录顺序、十进制原文、NULL 和 Base64 字节。预览前后无新增数据任务，独立查询确认测试表仍有原来的五行。临时容器与回环转发均已清理。
- PostgreSQL 原网格跳转和本页反选专项及 SQLite 原生窗口五项回归通过。
- MySQL 前两次验收分别因用例遗漏缓存页原勾选、刷新控件定位错误而停止。两个原始失败报告均保留，确认进程结束后清理对应容器，修正用例后通过。
