# 自定义比较键与字段映射

SQLite、PostgreSQL、MySQL 和 MariaDB 的单表比较可以指定异名字段，并使用一组非空且唯一的字段作为匹配键。适用于数据库迁移后的核对、只比较部分字段，以及没有主键但具有唯一业务键的表。

## 使用

1. 在表数据比较窗口选择左右表。展开「自定义匹配键与字段」。
2. 从两侧目录分别选择字段，点击「添加字段对」。勾选至少一对「用作匹配键」。多对勾选项按映射顺序组成联合键，每侧字段最多使用一次。
3. 点击「比较数据」。结果只比较所选字段，展开详情可核对两侧字段名和原值。需要反向核对时，可以交换左右，字段对会随方向反转。
4. 可在「比较方案」命名保存映射，也可以点击「恢复默认比较」，恢复同名主键和全部字段的比较方式。

## 范围

单次最多 64 对字段。比较时重新核对两侧真实字段目录。键值有 NULL 或在任一侧重复时，整个比较会报错。PostgreSQL、MySQL 与 MariaDB 的对应列仍须具有兼容的声明类型，SQLite 保留动态存储类型和精确值。筛选继续使用当前比较窗口的两侧同名筛选列。

SQLite 支持[自定义键与字段映射同步](sqlite-mapped-data-sync-20261108.md)。PostgreSQL、MySQL 和 MariaDB 的映射结果可用于只读比较。多表批次可以逐对选择默认比较或[自定义映射](data-compare-batch-column-mapping-20261108.md)，并将映射带入单表回查。

## 验证

2026-11-08 在 macOS arm64 通过运行时检查、严格类型检查、构建、14 项相关单测及 3 项 Electron 窗口测试。SQLite 跨文件验证无主键异名列映射、64 位键和二进制原值、方案恢复、换向、空键与重复键拦截。PostgreSQL 18.6 验证跨库无主键异名列。MySQL 8.4.11 与 MariaDB 11.4.13 验证跨引擎字段投影及无符号 64 位键。默认比较与单表同步流程通过回归。

网络实库使用 Server-200 上的隔离容器，测试后已清理。Windows 测试会话未连通，Windows 和安装包待验。
