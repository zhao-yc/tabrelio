# 多表同步预览逐表与逐行选择

SQLite、PostgreSQL、MySQL 和 MariaDB 的多表同步预览可逐表或逐行取舍。表对可以混用默认主键比较和自定义字段映射。

1. 在多表窗口选择要预览的插入、更新和删除操作。删除仍需主动勾选。
2. 点击「预览多表同步」。预览默认选中本次显示的差异。可取消整张表或某条记录，也可以取消或恢复全部差异。
3. 展开记录下的「查看字段差异」，核对两侧原值及异名字段。新增和删除行会显示对应的缺行提示。
4. 检查更新后的操作数和目标确认文字，输入确认文字并提交。调整选择后需要重新输入，全部取消时提交不可用。

确认只领取原预览中选中的记录，保留原有的事务、原值复核和冲突回滚。取消整张表后，该表不参与本次写入。单次提交沿用 100 条差异和 1 MiB 写入证据预算。候选可以通过[大批差异分页预览](data-compare-batch-large-preview-20261108.md)分批选择。

对标工作流参考 [Navicat 数据同步差异预览](https://help.navicat.com/hc/en-us/articles/115003576232-Can-I-check-for-data-differences-between-the-source-and-target-during-synchronization)。

## 验证

2026-11-08 在 macOS arm64 通过 Node.js 24.17.0 运行时检查、严格类型检查、构建、84 项相关单测及 4 项 Electron 窗口测试。SQLite 和 PostgreSQL 18.6 实测取消一张表及同表的其他记录，确认实际只更新一行，预览显示异名字段和两侧二进制原值。SQLite 另验取消全部、恢复全部、拒绝原确认文字以及保留取消删除的记录。MySQL 8.4.11 与 MariaDB 11.4.13 分别作为右侧，独立查询确认只写入各自选中的目标表。

网络实库使用 Server-200 隔离容器，验收后已清理。Windows 测试会话未连通，Windows 和安装包待验。
