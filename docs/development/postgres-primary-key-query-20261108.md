# PostgreSQL 原主键查询复制

1. 打开有主键的 PostgreSQL 普通表或分区表。选中一个数据格，或勾选本页需要定位的多条记录。
2. 点击「复制原主键查询 SQL」。有勾选时使用勾选范围，否则使用当前数据格所在行。
3. 将生成的 `SELECT` 粘贴到查询编辑器，核对 schema、表名和条件。复制动作本身只写普通文本。

复合主键按目录的主键顺序组成每条记录的条件，每条条件之间用 `OR` 连接，避免把不同记录的键值交叉组合。SQL 使用原页载入的主键，包括布局中隐藏的主键列。尚未提交的草稿不会更改条件。普通表使用 `ONLY` 沿用表页的读取范围，分区表查询其各分区。视图、无主键表和已截断的页不提供入口。缺少任一所需原值或超出生成预算时，整次拒绝。

## 验证

- macOS arm64 运行时、严格类型检查、构建和 376 项定向单测通过。
- 三项 macOS Electron 用例通过，连接 Server-200 上的隔离 PostgreSQL 18.6。复制专项从窗口复制事件捕获原文，用独立连接执行，确认复合键只匹配勾选的记录，排除交叉组合和继承子表同键记录，并覆盖两个分区。核对带引号的标识符、超出 JavaScript 安全整数的主键、空与非空二进制键、含反斜线的文本、草稿及无主键入口。
- 原 INSERT 和网格复制回归通过。隔离容器、匿名卷和回环转发已清理。

WIN11-TEST 无法连接。原生用例拦截本例复制事件，Windows、安装包和系统剪贴板写入待验。
