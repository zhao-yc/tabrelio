# 表和视图全量导出方案

在 MySQL、MariaDB 或 SQLite 的表页点「导出全部筛选行」，或在 PostgreSQL 表页点「导出数据」。配置文件格式、编码、格式选项和输出字段后，展开「导出方案」，填写名称并点「另存为新方案」。同一种数据库的其他表和视图可以应用此方案。

方案保留精确字段名及输出顺序。应用时，窗口会用当前对象的目录核对每个字段。缺少字段、当前对象无法使用该格式，或字段不符合 SQL 导出要求时，窗口会提示并保留原配置。成功应用后，重新选择文件并点击开始导出。全量数据导出继续使用当前表页的筛选和排序。

SQLite SQL 方案可以记录仅数据、仅结构或结构及数据。PostgreSQL 方案也可记录原生 COPY CSV 和普通表的完整 SQL 备份。仅结构和完整备份仍由对应导出入口决定范围。

表页方案与查询方案分开保存，各数据库类型各自独立。方案只记录名称、格式选项、字段名和版本，不保存筛选值、行数据、表身份、连接、文件位置或授权。
