# PostgreSQL 跨页勾选复制

在可插入的 PostgreSQL 表逐页勾选已有记录，并点击「收集本页复制目标」。返回原页可替换或移除该页目标。点「复制跨页收集记录」后，按页核对数量，再选择具体副本调整手工主键和唯一字段。

副本带入原记录及已暂存字段。生成、标识和序列默认列初始省略，由数据库提供值。点「暂存整批副本」后可整批撤销或重做，最后通过「预览记录修改」核对 SQL，再明确提交。

可读取原行身份的无主键表也可跨页收集。同一原记录重复出现、原页令牌过期或收集范围变化时，旧窗口无法暂存。一次最多收集 100 条，字段原值缓存上限为 4 MiB。复制、删除、填充收集和已有草稿共用 16 个原页名额。更改筛选、排序或页长时重新收集。

## 验证

- macOS arm64 运行时、严格类型检查、构建和 33 项相关单测通过。覆盖同页内行号隔离、暂存值、输入归属、重复定位、过期及草稿历史。
- macOS Electron 连接 Server-200 上的隔离 PostgreSQL 18.6。三个跨页用例覆盖手工主键逐条编辑、无主键表自动分配标识、第二条 INSERT 失败后的整批回滚。独立连接核对只新增两条副本，精确小数、二进制和 NULL 保持，序列及生成列由数据库处理。失败用例的触发器确认第一条已执行，回滚后原记录和两条草稿保持。
- 原跨页填充、删除和单行复制共五项原生回归通过。单行复制首轮缺少专用 schema，在产品操作前终止。补齐后用新实例通过，首轮日志保留。各临时容器、回环转发和匿名卷均已清理。

WIN11-TEST 会话无法连接，本轮在 macOS 完成源码窗口验收。Windows 和安装包待验。
