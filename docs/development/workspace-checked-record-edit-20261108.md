# MySQL 和 MariaDB 跨页逐条编辑

在有可靠定位键的 InnoDB 表中逐页勾选记录。到「多页草稿」点击「逐条编辑保留页勾选记录」。窗口按页号及原行顺序浏览勾选范围，并显示当前记录的来源页。

1. 为每条记录分别编辑所需字段。「保留本条输入」只更新窗口缓冲，可以继续到下一条。取消整组会丢弃本窗口的输入。
2. 点「暂存全部勾选记录」。原页草稿仅在整组来源、字段、输入及撤销预算均通过后更新。
3. 回到某页可单独撤销或重做其修改。通过「预览并提交」核对全部保留页的 SQL，再明确确认写入。

输入无效时可留在原窗口修正。原页、勾选、连接或草稿在编辑期间变化时，本批窗口会失效。不同保留页中的同一原定位不会被重复纳入同一个批次。

## 验证

- macOS arm64 运行时、严格类型检查、构建和 180 项相关单测通过。覆盖原页身份、仅后台页勾选、独立字段、非法候选及逐页撤销。
- macOS Electron 连接 Server-200 的隔离 MySQL 8.4.11 与 MariaDB 11.4.13。两种数据库均通过取消、非法 JSON 拒绝、修正后暂存、逐页撤销／重做和统一预览。独立连接确认仅所选两行按各自输入更新，12 位小数、未改字段及其它记录均按预期保留。
- 两种数据库均通过第二条 UPDATE 失败用例。回执确认首条更新已获服务器确认，随后整批回滚。独立连接仍读到原五行，原生窗口保留两页草稿。
- 首轮 MySQL 用例需为原值 NULL 的金额字段显式选择文本模式。修正测试交互后，四项最终实库用例均通过，初始失败日志保留。各临时容器和回环转发均已清理。

WIN11-TEST 会话无法连接，本轮在 macOS 完成源码窗口验收。Windows 和安装包待验。
