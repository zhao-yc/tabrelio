# 执行历史跨页全选

执行历史面板新增“选择当前筛选全部”。按钮从当前已应用筛选独立建立首页游标，逐页读取有界概要，最多接受现有 100 条勾选上限。扫描使用独立游标，不消费当前页面的续读句柄，因此全选完成后仍可继续读取原分页。

扫描过程中发现损坏记录、停止策略或超过 100 条时，整次操作失败并保留原选择，不产生部分选择。扫描只传输已有摘要，完整 SQL 和错误仍由原单条按需读取路径处理。关闭窗口、连接修订变化和取消请求沿用原任务收尾与游标释放保护。

验证范围：`ui-history-delete.test.tsx` 的跨页全选用例，历史时间筛选与耗时筛选相关 43 项定向测试，`node scripts/typecheck.mjs`，`node scripts/build.mjs`，`git diff --check`。

完整 Windows/macOS 安装、实际连接和跨平台原生验收仍按路线图单独执行。
