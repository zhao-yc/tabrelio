# 将完整查询结果导出到 Excel

在 MySQL 或 MariaDB 查询窗口点击「新执行并完整导出」，选择「Excel（XLSX）：每个行结果集一张工作表」，选择目标文件后确认执行。tabrelio 使用当前查询会话执行固定的 SQL 选区或全文一次。

每个行结果集按返回顺序写入「结果 1」「结果 2」等工作表。空结果保留标题，重名或空列标题按列位置区分。执行状态显示在窗口摘要。数字按文本保存，保留大整数、小数和浮点往返值。NULL 和二进制沿用 tabrelio 的可逆 Excel 文本协议。

工作簿固定使用 UTF-8，最多 64 张工作表、500 万个单元格（含标题）和 256 MiB 文件。每格最多 32,767 个字符。全程逐行写入，预览最多保留每组结果的 200 行。脚本成功、至少返回一个行结果集且工作簿完整写入后，才替换目标文件。取消、超限、会话断开或执行失败时保留原文件，已提交的数据库操作按服务器状态保留。

Navicat 的导出向导也支持查询结果和 Excel 格式。[Navicat 导出向导](https://www.navicat.com/manual/online_manual/en/navicat_18/win_manual/export_wizard.html)
