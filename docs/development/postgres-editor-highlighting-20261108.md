# PostgreSQL SQL 着色

打开 PostgreSQL 查询或带方言标识的 SQL 预览即可看到方言着色。跨行的 `$$` 和带标签字符串按原标签闭合，标签区分大小写。字符串里的 `--` 和 `/* … */` 仍属于正文。外层块注释要等内部注释闭合后才结束。双引号标识符、位置参数、类型转换和数值各有词法分类。[PostgreSQL 词法规则](https://www.postgresql.org/docs/18/sql-syntax-lexical.html)

空闲查询的普通单引号采用已知会话的 `standard_conforming_strings`。离线或尚未取得模式时使用 PostgreSQL 默认规则，`E'…'` 始终识别反斜杠转义。着色和模式切换沿用当前编辑器模型，补全、参数提示、片段和语句折叠仍使用原查询入口。

## 验证

- macOS 通过严格类型检查、构建与 123 项定向单元测试。补齐旧字号测试桩的模态选择器依赖。
- macOS Electron 离线 4 项通过。以实际渲染颜色区分字符串、注释和关键字，编辑标签中的一个字符并撤销，确认模型身份不变。同步回归片段、折叠及查询历史。保留首轮整段替换的撤销断言失败和一次片段自动弹出超时的原始记录，交付轮无跳过或失败。
- macOS Electron 连接 Server-200 隔离 PostgreSQL 18.6 的 4 项测试通过。核对两种会话字符串模式下的模型身份、函数补全和参数提示，以及片段、语句折叠和导航。会话、容器、匿名卷与隧道已清理。
- Windows 测试机不可达，本轮未验安装包。
