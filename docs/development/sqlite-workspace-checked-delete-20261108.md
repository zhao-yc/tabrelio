# SQLite 跨页勾选删除

在 SQLite 可编辑表里逐页勾选记录。「SQLite 多页草稿」显示各有效缓存页的勾选数，返回缓存页会恢复原勾选。点「删除保留页勾选记录」，核对确认框中的页号和数量，再将各页选中记录一起标记为待删除。可以回到对应页撤销或重做，也可以用「预览 SQLite 修改」核对整批 SQL 并明确提交。

勾选绑定到原快照和当次草稿版本。修改记录后需要重新勾选，撤销后也不会恢复已经撤销的勾选。有效勾选的原页受工作区原有 16 页预算保护。暂存前核对各原页是否有效、是否有在途操作，以及整批修改预算。提交前由原引擎核对原记录身份，事务中的冲突会回滚整批。

## 验证

- macOS arm64 运行时、类型检查、构建和 134 项相关单测通过。覆盖旧勾选失效、过期页、跨页预算、按原快照聚合和逐页撤销。
- 两个原生窗口专项分别验证提交和冲突回滚。确认取消保持勾选，缓存返回恢复勾选，暂存和预览期间独立读回原五行。提交只删除第 2、3 条。冲突用例在预览后用独立连接改动第 3 条，提交后磁盘仍有五行，外部值保留，两页删除草稿保持，任务回执记录整批回滚。
- 原 SQLite 多页草稿专项及网格、复制和跨页导出五项窗口回归通过。本轮合计 8 项原生窗口测试通过。
- 扩展单测时发现结构搜索快捷键的三个既有用例没有给提取式夹具注入 `appModalSelector`。相关测试及其提取的应用代码与基线一致，失败记录已保留。
