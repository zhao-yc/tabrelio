# 多表比较的自定义键与字段映射

SQLite、PostgreSQL、MySQL 和 MariaDB 的多表批次可以为每对表分别设置匹配键和字段映射。可在同一批次混用默认比较和自定义比较。

## 使用

1. 在「多表比较」中建立表对，在相应行点击「设置比较字段」。从两侧真实目录添加字段对，标记至少一对作为匹配键。多对键按映射顺序组成联合键。
2. 点击「比较所选表对」。未指定自定义字段的表对使用原有的同名主键和全部字段。已有字段映射但还未标记匹配键时，需补齐匹配键或恢复默认规则，才能运行及保存。
3. 编辑映射会清除该表对的旧结果，其余表对的结果保留。点击「打开表对」会带入这对表的自定义映射，手动重新比较后可查看两侧原值。
4. 保存多表方案时，各表对的字段映射一并保存。载入时核对表和字段目录，任何缺失都会保留当前配置和结果。整批换向会反转表和字段的左右关系，保留顺序和匹配键标记。

## 范围

每批最多 32 对表，每对最多 64 对字段。真实比较仍检查字段目录、声明类型、NULL 键、重复键及读取预算。自定义比较只读，单表回查沿用该规则。[SQLite 多表事务同步](sqlite-multi-table-sync-20261108.md)适用于使用默认规则的表对。网络数据库跨表事务同步和自定义映射结果的写入仍待实现。

## 验证

2026-11-08 在 macOS arm64 通过运行时检查、严格类型检查、源码构建、15 项相关单测及 3 项 Electron 窗口测试。SQLite 跨文件验证同批混用默认及自定义规则、无匹配键时阻止执行、方案重载、整批换向、字段改名时保留结果，以及回查携带映射。PostgreSQL 18.6 验证跨库无主键异名列的批次比较。MySQL 8.4.11 与 MariaDB 11.4.13 验证同一批次中的字段投影。既有方案和单表同步流程通过回归。
