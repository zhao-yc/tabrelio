# PostgreSQL 恢复文件离线检查

从「工具 → 执行 PostgreSQL SQL 文件」打开 UTF-8 SQL 后，点击「离线检查 SQL」。没有保存连接时也可以检查。恢复仍需选择目标，先前按离线模式选择的文件需在目标选定后重新选择。

从「工具 → PostgreSQL 自定义归档」选择 PGDMP 文件和本机 `pg_restore` 后，也可点击「离线检查 SQL」。检查沿用当前结构、数据、归档条目及所有者选项，在私有临时目录转换并检查 SQL。检查可以取消。结果只包含语句类别、内联 COPY 数据块和字节数，以及无法处理的指令、编码或文件外壳的问题类别与下一条语句序号。

文件逐块读取，使用与恢复共用的事务外壳、限制标记、内联 COPY 边界和指令规则。离线解析采用 PostgreSQL 默认标准字符串模式，跟踪常见的直接 SET 和 RESET。动态设置、语法语义、目标对象、权限和约束由实际数据库执行判断。检查结果独立于执行授权。 [PostgreSQL COPY 文档](https://www.postgresql.org/docs/18/sql-copy.html)
