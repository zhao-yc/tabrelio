# MySQL 和 MariaDB 跨页勾选填充

在有可靠定位键的 InnoDB 表里，逐页勾选要修改的已有记录。工作区保留已勾选页，切页时可返回原缓存。

1. 在「多页草稿」点击「填充保留页勾选记录」。
2. 核对弹窗中的页号、每页勾选数量和记录总数，选好字段并输入统一值。可以添加多个普通可编辑字段。
3. 点击「暂存整批草稿」。暂存保留勾选，每个涉及页各有一步撤销记录。回到某页撤销或重做时，其它页的草稿保持原样。
4. 点击「预览并提交」核对全部草稿和 SQL，确认后统一提交。

批量填充沿用当前页入口的字段类型、原值完整性及输入预算。每个保留页的原值必须和加载时对应，跨页合计校验记录数、单元格、字节和整组提交预算。参与修改的原定位有重叠时会拒绝整批。弹窗打开后，任一保留页、勾选、连接或历史代次变化都会使该弹窗失效。

## 验证

- macOS arm64 的运行时检查、严格类型检查、源码构建和 119 项相关单测通过。单测覆盖仅后台页有勾选、非法字段可修正、整组预算、重叠定位、勾选变动和无变化时不新增历史。
- macOS Electron 连接 Server-200 上的隔离 MySQL 8.4.11 和 MariaDB 11.4.13，两个提交用例均通过。取消和暂存时，独立连接读到原五行。预览确认后，只有第 2、3 条记录的文本和 12 位小数被更新，二进制旁列及其余记录原样保留。逐页撤销和重做也已验证。
- 两个数据库分别通过第二条更新触发失败的回滚用例。回执确认第一条更新已获服务器确认、整批事务已回滚，独立连接仍读到原五行，原生窗口仍可查看两页草稿。
- 原 MySQL 跨页勾选删除的 macOS 原生回归通过。五次原生用例均串行、零重试，隔离容器和回环转发已清理。
